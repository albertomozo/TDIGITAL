# Prompts para gestión de correos electrónicos 📧

Este documento propone prompts para gestionar correos electrónicos en diferentes fases: redacción, organización, respuesta y seguimiento.

## 1. Usos clave de IA para correos

- Redacción de mensajes claros y profesionales.
- Generación de asuntos atractivos y precisos.
- Respuesta rápida a correos recibidos con tono adecuado.
- Clasificación y ordenación de correos por prioridad o tema.
- Resumen de conversaciones largas en puntos clave.
- Revisión de ortografía y estilo antes de enviar.
- Creación de plantillas de correo para diferentes escenarios.
- Seguimiento de acciones pendientes y recordatorios.

## 2. Prompts para redacción

### 2.1 Correo profesional
```
Eres un asistente experto en comunicación profesional. Redacta un correo para [destinatario], con el objetivo de [objetivo del correo]. Incluye:
- saludo apropiado
- mensaje claro y breve
- llamada a la acción
- cierre cordial

Información adicional:
[detalles clave]

Tono: [formal/informal/amistoso]
Longitud: [breve/media/extendida]
```

### 2.2 Asunto de correo
```
Genera 5 asuntos de correo claros y atractivos para el siguiente mensaje:
[breve descripción del contenido o propósito]

Cada asunto debe tener menos de 60 caracteres y reflejar el beneficio o la acción esperada.
```

### 2.3 Corrección de estilo y gramática
```
Corrige el texto del correo para que sea claro, profesional y sin errores:
[texto del borrador]

Además, sugiere una versión más breve si es posible.
```

## 3. Prompts para respuesta a correos

### 3.1 Responder un correo recibido
```
Lee el siguiente correo entrante y escribe una respuesta apropiada:
- Destinatario: [quién envía]
- Contexto: [tema principal]
- Objetivo de la respuesta: [ej. confirmar, aclarar, disculparse, agendar]

Correo entrante:
[texto del correo]

Instrucciones adicionales:
- Sé conciso.
- Mantén un tono [formal/cercano].
- Incluye los próximos pasos claramente.
```

### 3.2 Resumen y respuesta combinada
```
Resume el correo siguiente en 3 puntos principales y redacta una respuesta breve con:
- confirmación de recepción
- respuesta a la pregunta principal
- próximos pasos

Correo:
[texto del correo]
```

## 4. Prompts para ordenación y priorización

### 4.1 Clasificar correos por urgencia
```
Clasifica estos correos en 3 niveles: urgente, importante y bajo prioridad. Explica brevemente la razón para cada clasificación.

Correos:
1. [asunto/resumen 1]
2. [asunto/resumen 2]
3. [asunto/resumen 3]
```

### 4.2 Agrupar correos por categorías
```
Agrupa estos correos en categorías: [clientes, proveedores, equipo, facturación, otros].
Para cada correo, indica la categoría y una etiqueta corta.

Correos:
- [resumen 1]
- [resumen 2]
- [resumen 3]
```

## 5. Prompts para seguimiento y recordatorios

### 5.1 Identificar tareas pendientes
```
Del siguiente hilo de correo, extrae las acciones pendientes y crea una lista de tareas con responsables y fechas tentativas.

Hilo de correo:
[texto del hilo]
```

### 5.2 Preparar un recordatorio
```
Redacta un correo recordatorio amable para [destinatario] sobre [asunto pendiente]. Incluye:
- motivo del recordatorio
- fecha límite o acción esperada
- tono respetuoso
```

## 6. Prompts para plantillas de correo

### 6.1 Plantilla de seguimiento
```
Crea una plantilla de correo para hacer seguimiento después de una reunión de trabajo. La plantilla debe incluir:
- saludo inicial
- agradecimiento por el tiempo
- resumen breve de acuerdos
- próxima acción
- cierre cordial
```

### 6.2 Plantilla de respuesta a solicitud
```
Crea una plantilla de correo para responder a una solicitud de información. Debe incluir:
- agradecimiento por la consulta
- respuesta clara a la petición
- opciones adicionales o siguientes pasos
- firma profesional
```

## 7. Consejos para usar los prompts

- Añade siempre el contexto necesario: nombres, fechas, objetivos y detalles relevantes.
- Define el tono adecuado según el destinatario: cliente, jefe, compañero, proveedor.
- Pide variantes si necesitas opciones diferentes.
- Usa prompts de resumen cuando el correo original es largo o técnico.
- Combina prompts de clasificación con la redacción para priorizar primero y responder después.

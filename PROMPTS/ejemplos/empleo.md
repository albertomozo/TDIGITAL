# Empleo — Prompts de ejemplo

Este archivo reúne prompts y consejos prácticos para crear, mejorar y adaptar un currículum vitae, así como para preparar una búsqueda de trabajo más efectiva con ayuda de IA.

Formato recomendado:
- Rol del asistente: "Eres un reclutador experto en [sector]".
- Contexto: experiencia, sector, nivel profesional y tipo de puesto.
- Objetivo: mejorar el CV, adaptar la candidatura o preparar entrevistas.
- Formato de salida: Markdown, lista de puntos, tabla o texto listo para copiar.

Consejos útiles para un currículum fuerte
- Destaca resultados concretos y métricas (por ejemplo, "incrementé ventas en un 20%") en lugar de solo tareas.
- Usa palabras clave extraídas de la oferta de empleo para mejorar la compatibilidad con sistemas de selección.
- Mantén el diseño limpio, claro y fácil de leer.
- Ajusta el currículum a cada candidatura en lugar de usar siempre el mismo texto.
- Añade enlaces a LinkedIn, GitHub o portafolio si son relevantes.
- Revisa ortografía, formato y coherencia antes de enviarlo.

Ejemplos de prompts

1) Crear o mejorar un currículum

```text
Eres un reclutador experto en [sector]. Ayúdame a crear un currículum vitae profesional y claro para un perfil de [puesto]. Incluye apartado de perfil profesional, experiencia, formación, habilidades y logros. Usa un tono profesional y un formato fácil de leer. Si es posible, añade versiones cortas y largas.
```

2) Adaptar el currículum a una oferta concreta

```text
Analiza esta oferta de empleo: [pega la oferta aquí]. Reescribe mi currículum para que se adapte mejor a esa vacante. Destaca experiencias y habilidades relevantes, mejora el texto para que sea más impactante y mantén un tono profesional. No inventes datos.
```

3) Mejorar la redacción de un perfil profesional

```text
Reescribe mi perfil profesional para que suene más sólido, moderno y orientado a reclutadores. Mi experiencia actual es: [describe tu experiencia]. Quiero destacar [habilidades o logros]. Devuélveme 3 versiones: una formal, una más comercial y una más breve.
```

4) Redactar una carta de presentación

```text
Escribe una carta de presentación breve y persuasiva para esta oferta de empleo: [pega la oferta]. Debe incluir un saludo formal, una introducción atractiva, una explicación de por qué encajo y un cierre profesional. Máximo 250 palabras.
```

5) Preparar una búsqueda de trabajo

```text
Actúa como coach de búsqueda de empleo. Ayúdame a crear un plan de búsqueda para conseguir un puesto de [puesto] en [ciudad/país]. Incluye fuentes de búsqueda, palabras clave para filtrar ofertas, mensajes de presentación y una estrategia para contactar a reclutadores y empresas.
```

6) Optimizar LinkedIn o perfil profesional online

```text
Revisa mi perfil de LinkedIn o mi perfil profesional online y sugiere mejoras para que sea más atractivo para reclutadores. Quiero destacar [sector], [experiencia] y [habilidades]. Devuélveme recomendaciones sobre título, resumen, experiencia y palabras clave.
```

7) Preparar una entrevista de trabajo

```text
Ayúdame a prepararme para una entrevista para un puesto de [puesto]. Hazme una lista de posibles preguntas y respuestas breves y profesionales. También incluye consejos para responder de forma clara, mostrar resultados y manejar preguntas sobre experiencia o cambios de trabajo.
```

8) Crear un checklist de candidatura

```text
Genera una checklist práctica para revisar una candidatura antes de enviarla: currículum, carta, LinkedIn, datos personales, ortografía, palabras clave y adaptación a la oferta. Formato de lista con casillas.
```

Sugerencias de uso
- Sustituye los campos entre corchetes por información real.
- Si tienes un currículum anterior, pídelo que lo reescriba manteniendo la honestidad y corrigiendo el tono.
- Pide siempre que te proponga varias versiones para comparar estilos.
- Usa la IA también para identificar debilidades en tu candidatura y mejorar la estrategia de búsqueda.

Ejemplo rápido de prompt final (lista para copiar)
"Eres un reclutador experto en marketing digital. Ayúdame a adaptar mi currículum a una oferta de Especialista en Marketing Digital. Destaca mi experiencia en campañas, análisis de métricas, SEO y automatización. Reescribe el texto para que suene más sólido, claro y orientado a resultados. No inventes datos y entrega el resultado en formato Markdown."
